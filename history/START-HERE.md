Это снимок принятой владельцем главной FRI от 9 ноября 2026. Сайт можно открыть локально сразу после распаковки.

1. Распакуй ZIP целиком. Открой `site/index.html` в браузере.
2. Для продолжения разработки открой распакованную папку в Codex. Вставь `PROMPT-CONTINUE.md` в новый чат и замени последнюю строку на свою задачу.

Если архив не читается, приложи отдельно `site/index.html`, `site/style.css`, `site/site.js`, `site/content.js`, `PROJECT-CONTEXT.md` и снимок нужного экрана. Графику приложи, когда она относится к задаче. Запускай и проверяй предложенные изменения в своей локальной копии.

## Локальный запуск

Текущая страница статическая, её файлы загружаются из папки сайта. Для предпросмотра по HTTP открой терминал **в распакованной папке FRI-Kirill** и выполни:

```powershell
python -m http.server 8139 --bind 127.0.0.1 --directory site
```

Открой http://127.0.0.1:8139/ в браузере. Остановка сервера — Ctrl+C. Если порт занят, замени 8139 в команде и адресе на свободный. Для этого способа нужен установленный Python.

Все значения для наполнения собраны в `site/content.js`. Точные даты, контакты и список спонсоров пока пусты. Кнопки входа и регистрации демонстрационные. Призовой фонд в принятом превью — **$20 000+**.
