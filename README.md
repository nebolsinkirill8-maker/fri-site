# First Russian International

Локальный сайт киберспортивного турнира FRI и материалы для продолжения разработки.

## Запуск

Нужен Node.js. Из корня проекта:

```sh
node serve.cjs
```

Открыть http://127.0.0.1:8139/ . Зависимостей для установки нет.
